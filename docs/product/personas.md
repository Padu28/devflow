# DevFlow — User Personas

## 1. Workspace Owner ("Demo User" / Engineering Lead)
- **Goals**: Set up the workspace, invite team members, configure roles, oversee multiple projects, and track overall delivery health via Analytics.
- **Pain points**: Needs confidence that ex-members or external users cannot access workspace data, and wants a fast overview without digging through spreadsheets.

## 2. Project Lead ("Priya Nair" / Admin or Member with Project Lead role)
- **Goals**: Customize Kanban columns and WIP limits, triage incoming tasks, assign owners, and keep sprint velocity predictable.
- **Pain points**: Stale board state when multiple teammates move cards simultaneously; needs real-time sync and conflict protection.

## 3. Contributor ("Alex Rivera" / Member)
- **Goals**: Pick up assigned tasks, break work into subtasks, move cards from `In Progress` → `In Review` → `Done`, and discuss blockers in comments.
- **Pain points**: Slow UI transitions and losing context when switching between projects; wants `⌘K` quick navigation and keyboard shortcuts.
